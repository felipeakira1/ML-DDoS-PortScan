# ML-DDoS-PortScan
Este repositório contém código e modelos para treinamento e avaliação de algoritmos de aprendizado de máquina voltados para a detecção de ataques DDoS (Distributed Denial of Service) e Portscan em redes de computadores.

#### 📋 Visão geral
O objetivo deste projeto é desenvolver e avaliar modelos de aprendizado de máquina capazes de identificar padrões maliciosos em tráfego de rede. Técnicas de pré-processamento, seleção de características e diferentes algoritmos de classificação são testados.

### 🛠️ Tecnologias Utilizadas
* Python 3.11+
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

### 📊 Conjunto de dados
Neste projeto foi utilizado o conjunto de dados CICIDS2017, que inclui tráfego de rede rotulado com atividades normais e maliciiosas.

### 🚀 Instruções de Uso
1. Clone este repositório
```
    git clone https://github.com/felipeakira1/ML-DDoS-PortScan.git
    cd ML-DDoS-PortScan
```
2. Crie um ambiente virtual e instale as dependências:
```
python -m venv myenv
```
3. Ative o ambiente virtual
```
source venv/bin/activate # Linux/Mac
myenv/Scripts/activate   # Windows
```
4. Instale as dependências
```
pip install -r requirements.txt
```
5. Execute os notebooks para análise e treinamento
